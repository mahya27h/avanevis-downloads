# بسته‌ی GPU آوانویس

با این بسته، موتور محلی [آوانویس](https://avanevis.netlify.app/) روی کارت گرافیک NVIDIA اجرا می‌شود و تبدیل گفتار به متن چند برابر سریع‌تر انجام می‌شود. این بسته فقط برای همین برنامه است و بدون کارت NVIDIA فایده‌ای ندارد.

**[دانلود بسته‌ی GPU](https://github.com/mahya27h/avanevis-downloads/releases/latest/download/Avanevis-gpu-pack-windows-x64.zip)** (حدود ۶۶۰ مگابایت)

## نصب

۱. برنامه را ببندید.

۲. فایل zip را باز کنید. همه‌ی فایل‌های پوشه‌ی `engine` بسته را در پوشه‌ی `engine` برنامه کپی کنید و جایگزینی فایل‌ها را تأیید کنید.

۳. برنامه را باز کنید و یک بار صدا را به متن تبدیل کنید. در «تنظیمات» ← «مدل‌های موتور محلی» باید نوشته باشد که موتور محلی روی کارت گرافیک اجرا می‌شود.

درایور NVIDIA باید نصب و به‌روز باشد. این بسته روی همه‌ی نسخه‌های آوانویس برای ویندوز کار می‌کند.
